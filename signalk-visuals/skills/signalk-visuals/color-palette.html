signalk-visuals color palette

Every color defined in the skill, as foreground on background. State colors are drawn as text and border on their own 0.16 tint over #0a0c0c (the thin console style uses 0.05); the tints are computed for this page, not values from the skill.

Page background and the theme-color meta tag. Constant in both modes.

Panel and card surface.

#0a0c0c --bg-panel-muted
Header band, neutral panels, input fields.
